# What is DevOps

- DevOps is a culture and set of practices that brings software development and IT operations together to removes the traditional barrier between developers, who write and improve software, and operations teams, who deploy and maintain it. 
- Instead of handing code over between teams, everyone shares responsibility accross the entire lifecycle so that we can deliver software faster, more reliably and with fewer manual errors
- In practice, this means using version control, automated testing, CI/CD pipelines, infrastructure as code, containers, and monitoring to make releases repeatable, observable, and low-risk.
