# Operating Systems and Interfaces

### What is an OS
* An OS is software that controls the hardware of a computer
* Consist off
  * Kernel
  * Shell
  * File System
  * Device Drivers
  * GUI
  * System libraries

### How do Machines Comunicate
- Communicate over network
- Protcols dictate the rules and contraints and allow machines to communicte with each other via network
- Communication happens via Ports
- Each Port has a unique number - 16 bit, (HTTP port 80, SMTP port 25, SSH port 22, FTP port 21)
