# Linux Notes

### Why learn Linux?

- Lightweight and efficient
- Free and open source
- Stable and reliable for long-running systems
- Used on desktops, servers, cloud platforms, embedded devices, and supercomputers
- Scales from small devices such as Raspberry Pi to large data centres
- Common in software development, cloud computing, and DevOps

### What is Linux?

Linux is a Unix-like operating system.

- Technically, Linux is the **kernel**: the core part of an operating system.
- The kernel manages hardware, memory, processes, and filesystems.
- A complete Linux operating system also includes a shell, system utilities, libraries, and applications.
- A packaged version of Linux is called a **distribution** or **distro** (example is ubuntu)

### What is a shell?

A shell is a command-line program that lets a user interact with the operating system. It:

- Accepts commands
- Runs programs
- Shows output and errors
- Allows automation using scripts

### What is Bash?

**Bash** stands for **Bourne Again SHell**.

- Bash is a commonly used Linux shell.
- It reads and interprets commands typed into the terminal.
- It can run individual commands or automated scripts.




### Linux terminal prompt

Example:

```text
ubuntu@ip-172-31-52-135:~$
```

- `ubuntu` = current user
- `ip-172-31-52-135` = server hostname
- `~` = home directory (`/home/ubuntu`)
- `$` = normal user prompt



### Paths

A path shows where a file or folder is stored.

```text
/home/ubuntu/tech613
```

| Symbol | Meaning |
|---|---|
| `/` | Root directory |
| `~` | Current user's home directory |
| `.` | Current directory |
| `..` | Parent directory |
