# S3

## What is S3
- S3 stands for Simple storage service, It is AWS's cloud object storage service used to store and to retrieve files (objects) such as documents, images and files - can retrieve any amount of data
- Provides built in redundancy (copy of data stored in min 3 AZs)
- equivalent to Azure Blob storage
- Data is stored in Buckets (containers in azure) - buckets are a container that holds your stored objects
- Objects refer to the file and its associated metadata (key is the unique name identifying the object)

- Basic Operations:
  1. Create a Bucket
  2. Upload a file as an object
  3. List stored
  4. Download an object
  5. Delete objects and remove empty buckets

AWS CLI: COmmand line interface for interacting with AWS services
Boto3: The AWS SDK for python, allowing python scripts to interact with AWS services

## Using S3 via AWS CLI

Setup:
- install python3n pip and venv
  - `sudo apt install -y python3 python3-pip python3-venv`
- install aws CLI:
  - `curl -fsSL https://awscli.amazonaws.com/v2/install.sh | sudo bash -s -- --system` (use aws --version to verify)
- configure AWS:
  - `aws configure`:
    - set ur access key, secret key and default region and format is json

### Manipulating S3 Buckets:

##### General commands
  - `aws s3 ls`: lists every s3 bucket in said region
  - `aws s3 help`: lists all options

##### create a bucket
  - `aws mb s3://<name> -- region <region name>`: creates a new bucket, region is optional - if not specified goes into default config region

##### Upload / download files from bucekts
  - `aws s3 cp <file> s3://<bucket name>`: This uploads a file to the S3 bucket (copies file)
  - `aws s3 ls s3://<bucket name>`: list all the objects in the bucket
  - `aws s3 sync s3://<bucket name> path`: downloads the content of a bucket into the specified path (doesnt delete from the bucket)

##### Deleting Files / Buckets
  - `aws s3 rm s3://<bucket name>/<object-name>`: delete an obkect inside of a s3 bucket
    - To remove all objects we dont specify the obkect name and use a `--recursive` tag: aws s3 rm s3://tech613-javed-first-bucket --recursive
  - `aws s3 rb "s3://<bucket name>`: Deletes a bucket MUST BE EMPTY first
    - to delete the bucket and all files inside it we add the --force tag

## Using S3 via python Boto3
- Boto3 is the AWS SDK (Software Development Kit) for Python. It allows Python programs to create, configure and manage AWS services, such as S3 and EC2.
- Allows us to automate AWS tasks with python code
- AWS CLI uses terminal commands, Boto3 uses python code

#### Set up:
-  Install python, pip and venv
-  start the venv inside your project folder:
   -  `python3 -m venv .venv`
   -  `source .venv/bin/activate`
-  Install boto3:
   -  `python -m pip install boto3`
   -  install any other requirements for your scripts such as argparse and save requirements
   -  `python -m pip freeze > requirements.txt`
-  aws configure (if not already done)

#### General Syntax:
- `import boto3`: needed at the start of evert file to use boto3
- `s3 = boto3.client("s3", region_name="eu-west-1")`
  - This creates a client obkect for interacting with S3
  - first argument selects the AWS service in this case "s3"

- Alternate: boto3

### S3 Commands

1. `s3.list_buckets()`: Lists buckets owned by the AWS account. (Same as `aws s3 ls` on AWS CLI.)

    ```python
    response = s3.list_buckets()
    ```

2. `s3.create_bucket()`: Creates a bucket in the specified region. (Same as `aws s3 mb` on AWS CLI.)

    ```python
    s3.create_bucket(
        Bucket=bucket_name,
        CreateBucketConfiguration={"LocationConstraint": "eu-west-1"}
    )
    ```

3. `s3.upload_file(local_file, bucket_name, object_key)`: Uploads a local file to a bucket. (Same as `aws s3 cp` from EC2 to S3.)



4. `s3.list_objects_v2(Bucket=bucket_name)`: Lists objects inside a specified bucket. (Same as `aws s3 ls s3://bucket-name/` on AWS CLI.)

    ```python
    response = s3.list_objects_v2(Bucket=bucket_name)
    ```

5. `s3.download_file(bucket_name, object_key, local_file)`: Downloads an object from a bucket to a local file. (Same as `aws s3 cp` from S3 to EC2.)

    ```python
    s3.download_file(bucket_name, object_key, local_file)
    ```

6. `s3.delete_object(Bucket=bucket_name, Key=object_key)`: Deletes a specified object from a bucket. (Same as `aws s3 rm` on AWS CLI.)

    ```python
    s3.delete_object(Bucket=bucket_name, Key=object_key)
    ```

7. `s3.delete_bucket(Bucket=bucket_name)`: Deletes an empty bucket. (Same as `aws s3 rb` without `--force` on AWS CLI.)
